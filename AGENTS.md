An offline, self-contained copy of the OSINT4ALL link board on start.me: 1,459 OSINT links in 78 panels, as one static page with no dependencies.

## What this is
- **What:** every link on https://start.me/p/L1rEYQ/osint4all, with the same panels, order and 4-column arrangement, plus search and collapsible panels.
- **For:** the owner, as a personal OSINT toolkit that keeps working if start.me changes or goes down.
- **Platform / stack:** plain HTML, CSS and JS. Node (no packages) only for the import script and the tests.
- **Money:** none. No hosting, no services.
- **What "done" looks like:** a double-click opens the board on either computer, and it matches the original's links.
- **Direction:** refresh from a new snapshot when the original changes.

## Settled decisions (don't re-argue)
- **Public, on GitHub Pages (owner, 2026-10-26)** at https://mbottega16.github.io/osint4all/, served from `main` at the repo root. Once live, a push to `main` publishes it. Auto mode won't flip a repo public, so the owner runs that step.
- **The data is copied, the page is not.** Link names, addresses, panel names and order follow the original. The design and code are this repo's own. The header says "Unofficial copy" and the footer credits OSINT4ALL and disclaims any affiliation. Keep both now that it's public, and don't copy start.me's markup, styles or branding.
- **No network calls of its own.** Favicons are files in `icons/`, the page sends no referrer, and links open with `noopener noreferrer`. The tests enforce this. An OSINT board shouldn't tell 270 sites that you opened it.
- **No build step.** `data/board.js` is a script the page loads, so `index.html` works straight from disk (`file://`) on both computers.
- **The original's 4 columns are kept at 1200 px and wider.** Narrower screens reflow to 3, 2 or 1 columns in reading order.
- **Almanac panels are the owner's additions (2026-10-26).** `data/almanac.js` adds 10 panels named `ALMANAC · <SUBJECT>` (242 teaching sites from the owner's Almanac library). They sit after the original's panels. The header and footer say they are not part of the original board. `board.js` stays the pure copy, and the original-match test reads only `board.js`.
- **Every panel starts closed (owner, 2026-10-26).** A first visit shows all panels collapsed. The viewer's own open and closed choices are kept after that. The storage key is `osint4all:closed:v2`; bumping it resets everyone to all-closed.
- **Separate from Atlas.** The vault's `projects/atlas/osint-board` mixes OSINT4ALL with SOCMINT and Atlas links. This repo is the pure copy. Don't merge them.

## How it's built
- `index.html` — the page shell: header, search, board, credit footer.
- `style.css` — colour tokens with a dark set that follows the system setting, plus the layout.
- `app.js` — draws `window.BOARD`, and handles search, collapsing (kept in `localStorage`, wrapped in try/catch) and the column count.
- `data/board.js` — the data: `window.BOARD = {title, source, snapshot, columns: [[{title, links: [{title, url, icon}]}]]};`, one link per line.
- `data/almanac.js` — the Almanac panels: `window.ALMANAC = {snapshot, panels: [{title, links}]}`. `app.js` puts each into the shortest column.
- `icons/` — one favicon per site, named after its domain. Generated by the import scripts.
- `scripts/import-almanac.mjs` — Almanac's `backend/seed/almanac-seed.json` → `data/almanac.js` + any missing `icons/`. One panel per subject, one link per site, skipping sites whose resources are all unreachable. It fetches missing favicons from Google's favicon service on your computer, never on the page.
- `scripts/import-scrape.mjs` — scrape files → `data/board.js` + `icons/`.
- `scripts/export-from-browser.js` — pasted into Chrome's console on the start.me page. It scrolls the whole board, collects every panel, link and icon, and downloads `osint4all-export.json`.
- `test/board.test.mjs` — data shape against the original, link sanity, icon files, no external loads, launcher pair.
- `Open OSINT4ALL.command` (Mac) / `Open OSINT4ALL.bat` (PC) — open the board in the default browser.

## Never Read / Noise Zones (Do Not Scan)
- `icons/` — about 1,280 binary favicons.
- `data/board.js` is about 165 KB: grep it for a link instead of reading it whole.

## Rules & Gotchas
- **start.me blocks scripted access.** Plain fetches get a 403, and a default headless browser never renders the board. Don't try to get past its bot check. A refresh needs the owner's own Chrome: `scripts/export-from-browser.js`, pasted into the console on the start.me page (paste the file's contents, not its path).
- **hs3x.com appears twice** in THROWAWAY CONTACT under two names. The original lists it twice, so keep both.
- **SOCMINT and GEOINT** link to sibling start.me boards. They are kept as on the original.
- **Panel names are the keys for remembered collapsed panels.** Renaming a panel forgets its state, and the test requires unique names.
- **Line endings:** the `.bat` must keep CRLF and the `.command` must stay executable. `.gitattributes` and the test cover both.
- **`.nojekyll`** stops GitHub Pages from running Jekyll over the files. Keep it.
